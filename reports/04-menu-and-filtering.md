# Отчёт 4. Консольное меню и фильтрация по типу дня

**Тема:** «Мобильный интернет-трафик — MobileUsage»

**Этап:** 4 из 5

**Дата выполнения:** 15 октября 2026 года

## 1. Цель работы

Создать консольное меню для работы с записями `MobileUsage` и реализовать обязательный пункт 5 — фильтрацию по типу дня с помощью метода `printByCategory()`.

## 2. Структура реализации

| Файл | Назначение |
|---|---|
| `model/MobileUsage.java` | Модель одной записи и проверка значений |
| `service/MobileUsageService.java` | Хранение, поиск и вывод записей |
| `app/MobileUsageApp.java` | Консольное меню и ввод пользователя |

Класс `MobileUsageService` хранит записи в списке `ArrayList<MobileUsage>`. Это позволяет добавить несколько дней и работать с ними без потери данных во время запуска программы.

## 3. Пункты меню

| Пункт | Действие |
|---:|---|
| 1 | Добавить новую запись |
| 2 | Показать все записи |
| 3 | Показать дни с трафиком больше 2000 МБ |
| 4 | Добавить три демонстрационные записи |
| 5 | Фильтровать записи по типу дня |
| 0 | Завершить программу |

## 4. Пункт 5 — `printByCategory()`

Пользователь вводит тип дня, например `оқу күні` или `демалыс`. Метод `printByCategory()` ищет записи без учёта регистра букв и выводит только подходящие.

```java
public void printByCategory(String dayType) {
    List<MobileUsage> filteredUsages = getByCategory(dayType);
    // вывод найденных записей
}
```

Если подходящих данных нет, приложение выводит сообщение: `Записи с типом дня «…» не найдены.`

## 5. Пример работы

После выбора пункта 4 добавляются следующие данные:

| Дата | Тип дня | Трафик | Wi-Fi |
|---|---|---:|---:|
| 12.10 | оқу күні | 1500 МБ | 6 ч. |
| 13.10 | демалыс | 2450 МБ | 8 ч. |
| 14.10 | оқу күні | 800 МБ | 4 ч. |

При выборе пункта 5 и вводе `оқу күні` программа выводит записи за 12.10 и 14.10. При выборе пункта 3 она выводит запись за 13.10, потому что 2450 МБ больше 2000 МБ.
