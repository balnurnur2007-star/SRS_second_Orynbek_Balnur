# Отчёт 1. Анализ задания и подготовка проекта

**Тема:** «Мобильный интернет-трафик — MobileUsage»  
**Этап:** 1 из 5  
**Дата выполнения:** 12 октября 2026 года

## 1. Цель работы

Подготовить основу консольного приложения для учёта того, сколько мобильного интернет-трафика расходуется за день и сколько часов проводится в сети Wi‑Fi. На следующих этапах приложение будет хранить записи по дням, определять дни с высоким расходом мобильного интернета и выводить данные по типу дня.

## 2. Постановка задачи

Необходимо разработать приложение `MobileUsage`, которое для каждого дня хранит следующие сведения:

| Поле | Тип | Назначение | Ограничение |
|---|---|---|---|
| `date` | `String` | Дата дня | Не пустая строка, формат `КК.АА` |
| `dayType` | `String` | Тип дня | Не пустая строка, например: «оқу күні», «демалыс» |
| `megabytes` | `int` | Объём мобильного трафика в МБ | От 0 до 100000 |
| `wifiHours` | `int` | Время в Wi‑Fi, часов | От 0 до 24 |

Главное правило программы: день считается днём с высоким расходом трафика, если использовано больше 2000 МБ мобильного интернета:

```text
isHeavyDay() = true, если megabytes > 2000
```

Также в меню должен быть пункт 5 — `printByCategory()`, который выводит записи выбранного типа дня.

## 3. Анализ входных и выходных данных

**Входные данные:** дата, тип дня, количество мобильного трафика в мегабайтах и количество часов Wi‑Fi. Позднее реальные значения будут подтверждаться скриншотами раздела Data Usage в настройках телефона.

**Выходные данные:** список сохранённых записей, сведения о днях с высоким трафиком и отфильтрованный список по типу дня.

## 4. Проектное решение

Для реализации будет использован язык Java и консольный интерфейс. Основные части программы:

```text
MobileUsage
├── src/main/java/         исходный код
│   ├── model/             класс MobileUsage
│   ├── service/           обработка и фильтрация записей
│   └── app/               меню и запуск программы
├── src/test/java/         проверки модели и сервиса
├── reports/               пять отчётов по этапам
└── evidence/              реальные скриншоты Data Usage
```

Такое разделение позволяет не смешивать данные, бизнес-логику и взаимодействие с пользователем.
