# Отчёт 3. Определение дня с высоким расходом трафика

**Тема:** «Мобильный интернет-трафик — MobileUsage»

**Этап:** 3 из 5

**Дата выполнения:** 14 октября 2026 года

## 1. Цель работы

Реализовать правило, которое определяет дни с высоким расходом мобильного интернета.

## 2. Правило

По условию задания день считается «тяжёлым», если мобильный трафик строго больше 2000 МБ:

```text
megabytes > 2000
```

Значение, равное 2000 МБ, не является высоким расходом, потому что в условии используется знак «больше», а не «больше или равно».

## 3. Реализация

В класс `MobileUsage` добавлен метод:

```java
public boolean isHeavyDay() {
    return megabytes > 2000;
}
```

Метод возвращает `true`, если значение поля `megabytes` превышает 2000, и `false` во всех остальных случаях.

## 4. Проверка работы метода

| Дата | Тип дня | Трафик, МБ | Ожидаемый результат `isHeavyDay()` |
|---|---|---:|---|
| 12.10 | оқу күні | 1500 | `false` |
| 13.10 | демалыс | 2000 | `false` |
| 14.10 | оқу күні | 2001 | `true` |

Для проверки добавлены тесты в файл `src/test/java/model/MobileUsageValidationTest.java`.

Особенно проверены граничные значения:

```java
new MobileUsage("13.10", "демалыс", 2000, 4).isHeavyDay(); // false
new MobileUsage("14.10", "оқу күні", 2001, 8).isHeavyDay(); // true
```

## 5. Результат

В классе `MobileUsage` реализован метод `isHeavyDay()`. Он корректно отличает обычные дни от дней с высоким расходом мобильного трафика. В следующем этапе этот метод будет использоваться в консольном меню программы.
